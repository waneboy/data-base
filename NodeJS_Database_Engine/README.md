# Курс: Разработка реляционной SQL СУБД на Node.js с нуля

Методическое руководство и практический интенсив по системной инженерии баз данных. В курсе последовательно разбирается, как устроены СУБД под капотом, на каких языках их пишут в индустрии (C, C++, Rust, Go, Java), в чем преимущества использования Node.js и как шаг за шагом написать собственную полноценную SQL-СУБД с транзакциями, сетевым сервером, парсером запросов и дисковым движком хранения.

Оптимизатор запросов с автоматическим выбором $O(1)$ индекса при `WHERE id = X`. | [Открыть лекцию](./Lesson%206/lesson%206.md) |

Сетевой сервер на базе модуля `node:net` и длина-префиксный сетевой протокол (*Wire Protocol*). Написание клиентской библиотеки (`TinyClient SDK`) и демонстрация банковского перевода с откатом при сбое. | [Открыть лекцию](./Lesson%207/lesson%207.md) |
| **Урок 8** | **Финальный проект: CLI-интерфейс (REPL), запуск и бенчмаркинг** | **Практика:** Сборка СУБД **TinySQL** в готовый монолитный дистрибутив. Разработка интерактивной терминальной консоли REPL (`cli.js`). Стресс-тестирование и бенчмарк (`benchmark.js`): сравнение скорости выборки по индексу против Full Table Scan (ускорение более чем в 1000 раз!). Итоги и темы для дипломных работ. | [Открыть лекцию](./Lesson%208/lesson%208.md) |

## 🛠️ Архитектура разработанной СУБД TinySQL

```
┌────────────────────────────────────────────────────────────────────────┐
│                        TINYSQL SYSTEM OVERVIEW                         │
├────────────────────────────────────────────────────────────────────────┤
│  CLI Консоль (cli.js)  ◄─── TCP Сокет ───►  TinyClient SDK             │
├────────────────────────────────────────────────────────────────────────┤
│  Сетевой сервер (server.js) — Wire Protocol (длина-префикс 4 байта)    │
│  Сессионный менеджер транзакций: BEGIN / COMMIT / ROLLBACK (Undo Log) │
├────────────────────────────────────────────────────────────────────────┤
│  Компилятор SQL: Лексер (lexer.js) ──► Парсер AST ──► Оптимизатор     │
├────────────────────────────────────────────────────────────────────────┤
│  Движок выполнения (executor.js): сканирование, фильтры, сортировка    │
├────────────────────────────────────────────────────────────────────────┤
│  Движок хранения (storage.js): Bitcask (Append-Only Log + RAM Keydir) │
│  Контрольные суммы CRC32 (IEEE 802.3) + Фоновое сжатие (Compaction)   │
├────────────────────────────────────────────────────────────────────────┤
│  Журнал предзаписи WAL (wal.js): fsync() для гарантии Durability (ACID)│
└────────────────────────────────────────────────────────────────────────┘
```

## 🚀 Быстрый старт

### 1. Запуск интерактивной консоли CLI (встраиваемый режим):
```bash
cd "Lesson 8"
node cli.js
```

### 2. Запуск сетевого TCP сервера и клиента:
```bash
# В терминале 1: запуск сервера
cd "Lesson 8"
node src/server.js

# В терминале 2: запуск CLI (автоматически подключится по TCP)
cd "Lesson 8"
node cli.js
```

### 3. Запуск нагрузочного бенчмарка:
```bash
cd "Lesson 8"
node benchmark.js
```

### 4. Запуск всех практических тестов:
```bash
# Тестирование Storage Engine и Compaction:
node "Lesson 5/test_storage.js"

# Тестирование SQL Lexer, Parser и Executor:
node "Lesson 6/test_parser.js"

# Тестирование TCP Server, Client SDK и ROLLBACK:
node "Lesson 7/demo_client.js"
```
