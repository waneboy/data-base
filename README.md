# Практические курсы по базам данных

Методические руководства, лекционные материалы и практические проекты по современным системам управления базами данных (СУБД). Курс содержит 8 глубоко структурированных лекций — от фундаментальной истории зарождения баз данных, теории реляционных моделей Эдгара Кодда и анализа системных языков программирования (C, C++, Rust, Go, Java) до разработки **собственной полноценной реляционной SQL СУБД с нуля на языке Node.js**.

## 🚀 Быстрый старт с собственной СУБД (TinySQL)

СУБД написана на чистом JavaScript (ES Modules) и не требует сторонних зависимостей (`node_modules`). Достаточно установленного Node.js версии 18+.

### 1. Клонирование репозитория:
```bash
git clone https://github.com/<ваш_аккаунт>/databases_lessons.git
cd databases_lessons/NodeJS_Database_Engine/Lesson\ 8
```

### 2. Запуск интерактивной консоли CLI (встраиваемый режим):
```bash
node cli.js
```

### 3. Пример взаимодействия с базой через SQL:
```sql
tinydb> CREATE TABLE users (id, name, age, city);
✓ Таблица 'users' успешно создана (поля: id, name, age, city) [1.20 ms]

tinydb> INSERT INTO users VALUES (1, 'Иван', 20, 'Москва');
✓ 1 запись успешно добавлена (ID=1) [0.85 ms]

tinydb> INSERT INTO users VALUES (2, 'Анна', 22, 'Санкт-Петербург');
✓ 1 запись успешно добавлена (ID=2) [0.72 ms]

tinydb> SELECT * FROM users WHERE age >= 20 ORDER BY id DESC;
┌─────────┬────┬────────┬─────┬───────────────────┐
│ (index) │ id │ name   │ age │ city              │
├─────────┼────┼────────┼─────┼───────────────────┤
│ 0       │ 2  │ 'Анна' │ 22  │ 'Санкт-Петербург' │
│ 1       │ 1  │ 'Иван' │ 20  │ 'Москва'          │
└─────────┴────┴────────┴─────┴───────────────────┘
Выбрано строк: 2 [0.45 ms]

tinydb> .exit
```

### 4. Запуск клиент-серверного режима:
```bash
# Терминал 1: Запуск демона базы данных
node src/server.js

# Терминал 2: Подключение консоли клиента по TCP
node cli.js
```

### 5. Запуск нагрузочного бенчмарка:
```bash
node benchmark.js
```
